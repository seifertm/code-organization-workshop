# Slides: Code Organization Workshop

This is a Reveal.js slide deck for a workshop on pragmatic code organization.

## Prerequisites
- Node.js and npm installed

## Setup

```bash
npm install
```

## Run locally

```bash
npm run start
# Open http://localhost:8080
```

## Edit slides
- Main deck: `slides.md` (Markdown). Top‑level `---` separates slides; `--` creates vertical stacks.
- HTML shell: `index.html` configures Reveal and loads the markdown.

## Notes
- Speaker notes: add lines starting with `Note:` in markdown and press `s` during the presentation.
- Theme: change the stylesheet in `index.html` (e.g., `black.css`, `simple.css`, `beige.css`).
